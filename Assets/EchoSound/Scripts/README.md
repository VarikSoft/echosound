# Как ориентироваться в скриптах

Читайте в таком порядке:

1. **Generation/LevelGenerator.cs → Generate()** — главный сценарий: построить карту, выбрать префабы, поставить комнаты, отправить событие.
2. **Generation/RoomGraph.cs** — алгоритм карты. `BuildConnectedRooms` добавляет связанные комнаты, `AddExtraConnections` создаёт обходные пути. Здесь нет GameObject и игрока.
3. **Rooms/RoomCatalog.cs → Pick()** — выбор префаба по входам, повороту и весу.
4. **Rooms/RoomTemplate.cs** — сведения о префабе: название, размер, безопасный Anchor и дочерние входы.
5. **Testing/GenerationPlayground.cs** — связывает тестовую сцену с генератором и игроком.
6. **Player/FirstPersonPlayer.cs** — камера, ходьба, бег, прыжок и перенос игрока.

Дополнительные небольшие файлы:

| Файл | Назначение |
|---|---|
| Generation/GeneratedLevel.cs | Результат генерации: карта и размещённые комнаты |
| Rooms/DoorLayout.cs | Четыре стороны света, флаги входов и их повороты |
| Rooms/RoomDoor.cs | Маркер одного входа и его Gizmos |
| Rooms/RoomMarker.cs | Подписанные точки для будущих секретов, загадок и монстров; без игровой логики |

Объекты комнат и внутренние проходы настраиваются в **префабах**, а не в этих скриптах. Новые варианты добавляются в **DefaultRooms.asset**.

Скриптов мини-карты, артефактов, фонаря и интерфейса здесь нет. Настройка редактора и проверки находятся отдельно в `../Editor`.
