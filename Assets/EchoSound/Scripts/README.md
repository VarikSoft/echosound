# Как ориентироваться в скриптах

Читайте в таком порядке:

1. **Generation/LevelGenerator.cs → Generate()** — главный сценарий: построить карту, выбрать префабы, поставить комнаты, отправить событие.
2. **Generation/RoomGraph.cs** — алгоритм карты. `BuildConnectedRooms` добавляет связанные комнаты, `AddExtraConnections` создаёт обходные пути. Здесь нет GameObject и игрока.
3. **Rooms/RoomCatalog.cs → Pick()** — выбор префаба по входам, повороту и весу.
4. **Rooms/RoomTemplate.cs** — сведения о префабе: название, размер, безопасный Anchor и дочерние входы.
5. **Testing/GenerationPlayground.cs** — связывает тестовую сцену с генератором и игроком.
6. **Player/FirstPersonPlayer.cs** — камера, ходьба, бег, прыжок и перенос игрока.
7. **Sound/SoundBus.cs** — шина событий звука: эмиттеры генерируют звуковые волны, слушатели (ИИ, эхолокация, аудио) реагируют.
8. **VFX/EcholocationManager.cs** — менеджер эхолокации: слушает шину звука, ведет активные импульсы и передает их в глобальные параметры шейдеров.

Дополнительные небольшие файлы:

| Файл | Назначение |
|---|---|
| Generation/GeneratedLevel.cs | Результат генерации: карта и размещённые комнаты |
| Rooms/DoorLayout.cs | Четыре стороны света, флаги входов и их повороты |
| Rooms/RoomDoor.cs | Маркер одного входа и его Gizmos |
| Rooms/RoomMarker.cs | Подписанные точки для будущих секретов, загадок и монстров; без игровой логики |
| Sound/SoundEvent.cs | Структура события звука (позиция, радиус, громкость, тип, источник) |
| Sound/SoundType.cs | Категории звука (шаги, прыжки, приземление, терминал/камера, голос, шум) |
| Sound/ISoundListener.cs | Интерфейс для сущностей, слышащих звук (враги, напарник) |
| Sound/SoundEmitter.cs | Универсальный компонент на объектах (двери, кнопки, приманки) |
| Sound/PlayerSoundEmitter.cs | Отслеживание шагов, прыжков и приземления игрока |
| Sound/PushToTalkVoice.cs | Локальный микрофон по удержанию V, индикатор и звуковые события от речи |
| Sound/VoiceActivity.cs | Измерение громкости PCM и порог отсечения тишины |
| Sound/AcousticField.cs | Расчёт путей распространения звука с учётом стен и проходов |
| Sound/SoundListenerComponent.cs | Базовый компонент-слушатель для монстров и напарника |
| Sound/SoundDebugVisualizer.cs | Визуализатор звуковых волн в Scene view через Gizmos |
| VFX/EcholocationConfig.cs | Настройки скорости волн, затухания, сетки и палитры цветов по типам звуков |
| VFX/EcholocationEffect.cs | Полноэкранный пост-эффект на камеру игрока или терминала (реконструкция по глубине) |

Объекты комнат и внутренние проходы настраиваются в **префабах**, а не в этих скриптах. Новые варианты добавляются в **DefaultRooms.asset**. Шейдеры эхолокации находятся в `../Shaders`. Настройка редактора и проверки находятся отдельно в `../Editor`.
